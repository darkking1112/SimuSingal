### 过程中修复的问题

- **信号生成**：`collection_gen._place_signals` 只按信号**实际**占用区间选频点，而
  `plan_signal` 入口还会按**标称带宽**复查基带范围；数字样式的实际带宽由 sps 取整得到、
  可能小于标称带宽，于是带宽较大时会间歇生成失败（旧集合带宽占比小而未暴露）。
  改为取两条规则的公共区间，36 000 次抽样验证零失败，三个新集合生成失败数也为 0。
- **生成结果可见性**：勾选 AMC 标注时，写不进类别字典的样式（如 `am`、跳频）此前只写
  `out_of_taxonomy` 标签，生成结果里没有任何计数，界面预留的"类别映射之外"一行拿不到数据。
  现在项目引擎与 TorchSig 一样返回 `unmapped`（如 `{"AM": 29}`）。
- **训练页可见性**：`build_rows` 为 AMC 统计被跳过的标签状态（`unlabeled`/`unknown`/
  `out_of_taxonomy`），训练页集合下拉下方显示"训练集 N 个样本（M 条资产），跳过 …"，
  不再出现"选了 200 条资产、训练只有 171 个样本"而页面上毫无解释的情况。
