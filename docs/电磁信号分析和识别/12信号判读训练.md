# 信号判读训练

版本：0.1.0。更新日期：2026-11-05。

「信号判读训练」是信号分析桌面应用的第十二个标签页，是一个**独立的人工判读训练模块**：页面生成 5 s 归一化中频信号，学生根据**时域波形、瞬时频谱、累积频谱**以及按题型自动打开的辅助视图判断信号类型，再从右侧单题库中选择并判卷。页面不读取、不写入工作区资产或运行记录数据库，也不依赖 `training/` 下的外部训练流程。

本页与「调制识别」「AMC 识别训练」的区别是：后两者训练/调用自动识别模型，本页只训练人的判读能力；答案判断为题库真值与选择项的直接比较，不使用模型推理。

**单音 LINK11** 是教学简化样式：单音载波叠加 1364 Bd 的 OOK 突发门控，用来训练“单音 + 突发图案”的判读，不复刻真实 LINK11 协议。**多路音频**是 4～6 路 FDM 音频子带，每路带 1～2.2 kHz 的音频调制；它与由离散纯音组成的“多音”不同。

## 3. 三个按钮与状态

内部状态由 `phase`（`ready / playing / paused / ended`）和 `revealed` 两个字段描述：

| 按钮 | 文案 | 行为 |
|---|---|---|
| 重新开始 | 固定 | 停止播放，生成新题，`t=0`，清空选择与答案；保留本轮统计；不自动播放。 |
| 播放 | `▶ 播放` → `⏸ 暂停` → `▶ 继续` → `↻ 重播` | 5 s 内按 30 fps 推进播放位置；暂停后从原位置继续；结束后再按从 0 重播；答题后仍可重播复习。 |
| 显示答案 | 固定 | 暂停播放，比较选择与真值，显示正确/错误、标准答案、判读依据和易混点；第一次显示时计分。未选择时弹出确认框，按“未作答”处理。 |

```text
READY --播放--> PLAYING --暂停--> PAUSED --播放--> PLAYING
PLAYING --t>=5s--> ENDED --播放--> PLAYING(t=0)
任意 --重新开始--> READY(新题)
任意 --显示答案--> revealed=True，并暂停
revealed=True 后：类型选择禁用；播放、重播、重新开始仍可用
```

计分口径：只有第一次“显示答案”计分；有选择时 `answered_count += 1`，正确时 `correct_count += 1` 且连续数加一，错误或未作答时连续数归零；`重新开始` 只换题，不清空统计。

## 4. 三幅主图

| 图 | 口径 | 作用 |
|---|---|---|
| 时域波形 | 播放位置附近 5 ms 原始中频采样，可切 1/5/10/20/50/100 ms；下方滑块定位 5 s 记录 | 观察载波周期、幅度恒定、两电平、突发、多电平、跳频相位突变 |
| 瞬时频谱 | 当前播放位置前 20 ms，Hann 窗，`NFFT=4096`，`hop=10 ms`，单边谱 | 观察当前跳频信道、突发是否在“开”状态、当前符号附近的谱峰 |
| 累积频谱 | 随播放位置从第 0 帧累积到当前帧；拖到 5 s 时为整段最大保持 + 平均 | 观察谱峰/频带如何随时间逐步出现；答题时显示完整 5 s |

固定参数与口径：

```text
fs = 200 kHz, T = 5 s, f_IF = 45 kHz
x(t) = Re{ s_b(t) · exp(j2π f_IF t) } + n(t)
显示 0～fs/2 单边谱；频率轴 0～100 kHz
```

- 所有频谱共用同一个 dB 参考（全段最大谱峰）；播放只索引预计算的 STFT，不在 30 fps 定时器里做 FFT。
- 累积谱初始只显示第一帧（约 0～20 ms），随播放位置逐帧累加；拖到 5 s 或播放结束时为完整 5 s 结果。答题“显示答案”时会直接展示完整 5 s 作为判读依据。
- 时域图不再做 min/max 包络抽取：5 s × 200 kHz 共 100 万点，屏幕无法逐点显示，因此默认只画播放位置附近 5 ms 的原始采样；需要看整段时用下方滑块定位，整段结构由时频辅助图承担。
- 4FSK/8FSK 的主峰数由累积最大保持谱检测：门限 `峰值 − 8 dB`，最小间距 `max(300 Hz, 0.5×音间隔)`；答案卡显示“累积谱主峰 8”等测量值。

## 5. 辅助视图

### 5.1 星座图

- 用于 BPSK/QPSK/8PSK、16QAM/64QAM；PSK/QAM 阶数**不能**只靠幅度谱判断。
- 生成时保存已知符号定时下的接收符号点（含噪声）与理想星座点；页面绘制 I/Q 散点，PSK 叠加单位圆，答题后叠加理想点。
- 64QAM 约 2500～4000 个点，信噪比 24～30 dB；答题后叠加 8×8 理想点。
- FSK/模拟/突发类切换到星座页时显示“该题型无星座，请用时频/累积谱”，不会出现空白。

### 5.2 IQ 相位

- 当前播放位置附近 50 ms 的基带 I、Q 时域轨迹。
- BPSK 的 Q 路近似为 0；QPSK/8PSK 两路均有跳变；QAM 呈多电平；也可辅助观察 FSK 的双频振荡。

### 5.3 时频 / 跳频

- 使用与累积谱相同的 STFT 矩阵，显示 0～5 s × 0～100 kHz 的时频图。
- 2FSK 突发显示周期门控缺口；跳频 2FSK 显示中心频率台阶，并叠加峰值频率轨迹；多路音频显示多条平行音频子带。
- 时频图只作为辅助证据，不替代三幅主图。

## 6. 门控 / 跳频生成层

突发与跳频不散落在各调制生成器里，而是由统一的 `GateSpec` / `HopSpec` 施加：

```text
x(t) = gate(t) · s_mod(t, f_hop(t)) + n(t)
```

- **2FSK 突发**：2FSK 基带 × 周期门控；突发 80～180 ms，间隔 30～90 ms，升余弦边缘 1 ms。
- **跳频 2FSK**：8 个基带信道 `−28…+28 kHz`，驻留 12～50 ms，随机排列；跳变处使用 0.5 ms 升余弦幅度凹陷抑制带外溅射。
- **单音 LINK11**：单音载波 × 1364 Bd OOK × 慢突发门控。
- **多路音频**：4～6 路 FDM 音频子带，子载波间隔 6.5～8 kHz，每路音频带宽 1～2.2 kHz。

累积最大保持谱因此能显示突发带、跳频多频带或多音频子带；时频图显示时间顺序。

## 7. 代码与测试对应

```text
src/signal_analysis/drill/
  catalog.py       # 20 类单题库、分组、判据、默认辅助页
  waveforms.py     # 基础调制波形、星座/噪声、实中频转换
  patterns.py      # GateSpec / HopSpec、门控与跳频
  features.py      # STFT、累积谱、峰值检测、包络/带宽/平坦度、IQ 窗口、跳频轨迹
  session.py       # 出题、播放、选择、判卷、计分状态机

src/signal_analysis/ui/pages/signal_drill_page.py  # 页面与绘图
tests/analysis/test_signal_drill.py                # 核心单测
tests/analysis/test_signal_drill_gui.py            # 离屏 GUI 流程
```

核心入口：

- `DrillSession.new_round()`：从单题库类型袋抽题，生成 `SignalSpec`、`Waveform`、STFT 和答案特征。
- `DrillSession.play/pause/advance/seek`：播放状态机。
- `DrillSession.select/reveal`：选择与判卷；`AnswerResult` 带判读依据、测量值、易混点。
- `SignalDrillPage`：三主图、三辅助页、单题库、三按钮；不写工作区数据库。

测试覆盖：

- 20 类均能生成有限实中频记录；
- 4FSK/8FSK 的累积谱主峰数稳定为 4/8；
- BPSK/QPSK/8PSK/16QAM/64QAM 的星座簇数为 2/4/8/16/64；
- 2FSK 突发、跳频、单音 LINK11、多路音频的门控/跳频/子带特征；
- 播放→暂停→继续→结束→重播、答对/答错/未作答、重新开始保留统计；
- 页面离屏渲染、辅助页自动切换、三按钮流程。

## 8. 已知边界

- 中频是归一化仿真值（`f_IF=45 kHz`），不模拟 70 MHz 射频前端，也不直接接声卡；“播放”是视觉回放。
- 星座图使用生成器的已知符号定时，不做盲载波/定时恢复；这是教学辅助视图，不是接收机性能评估。
- 单音 LINK11 是教学简化，不是协议级复刻；多路音频也以可判读的 FDM 单音/窄带子带为主。
- 页面不保存答题记录；教师需要统计时可在后续版本增加导出。
- 题库按可辨识性设计：PSK/QAM 阶数必须打开星座图，4/8FSK 以累积谱主峰数判阶，突发/跳频以时频结构辅助。
